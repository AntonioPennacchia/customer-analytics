# Data Model

## Overview

This section describes the conceptual data model behind the Wossist customer analytics ecosystem.

The objective is to define the main business entities, their relationships and the data structure required to support customer analytics use cases.

The model is designed around the customer lifecycle, from marketing interactions to policy purchase and customer retention.

---

## Main Entities

The Wossist data model includes the following main entities:

- Customers
- Products
- Sales Channels
- Campaigns
- Operators
- Customer Interactions
- Quotes
- Policies
- Renewals

---

## Data Model Evolution

The data model is designed as an evolving business asset.

Additional entities and data sources can be progressively introduced to support new analytics scenarios.
